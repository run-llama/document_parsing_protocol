# Ground Truth — Images, Diagrams and Other

Workflow for pages carrying figures: images, logos, diagrams, maps, schematics, floor plans,
chemical structures and printed music. The rules themselves live in the protocol; this page only
says what to do around them.

1. **Classify the figure before transcribing it.** Decide what it really is — text, chart, graph,
   labelled schematic, photo — and pick the encoding from [[Images]].
2. **Flag every page that falls under an open point**, so the page can be revisited when the point
   closes:
   - a logo that carries no legible text — [[Logos]];
   - a floor plan or architectural drawing — [[Blueprints]];
   - a circuit schematic — [[Electrical Schematics]];
   - a map, and always a data map whose values have no printed key or one that needs both a
     description and a table — [[Geographic Maps]];
   - a labelled conceptual diagram — [[Slide Diagrams]];
   - a page of printed staves — [[Music Notation]].
3. **Flag an unreadable part of a chemical structure** alongside the words that describe it, so a
   reviewer can check the source rather than the guess — [[Chemical Molecules]].
4. **Check an organisation chart's edges against the printed rules**, one box at a time; do not add
   an edge the page does not draw — [[Diagrams and Flowcharts]].
5. **Before publishing a figure page, compare every printed string on the figure with the output**
   — labels, legend entries, scale bars, callouts, captions. A missing string is the most common
   defect on these pages.
