# Ground Truth — Marks on the Page

Steps for producing ground truth on pages that carry marks, stamps and symbols. Each step serves
the rule it links to; the rule, not this list, says what the output is.

1. **Clipped text** — flag a page whose text runs off the edge, and record the clipping in the
   page's review notes, never in the transcription. Serves [[Clipped Text]].
2. **Unreadable handwriting** — flag the page when part of a handwritten note cannot be read, so
   the left-out words are visible to review. Serves [[Handwritten Annotations]].
3. **Obscured characters** — flag a page where an overprint hides characters, noting which string
   lost them. Serves [[Overlapping Text]].
4. **Seals with no legible text** — flag the page whenever the bare `[seal]` is used. Serves
   [[Seals and Round Stamps]].
5. **Codes that do not decode** — still draw the code's own box, then flag the page. Serves
   [[QR Codes and Bar Codes]].
6. **Open encodings** — flag every page where a value-bearing icon, a meaningful text colour or a
   watermark was encoded, so the page can be revisited when the open point closes. Serves
   [[Iconography and Symbols]], [[Text Colors]] and [[Watermarks]].
